## 本仓修改

### 管理端

- `useTableQuery` 接收实际返回的 pageSize，修复 URL 没有 size 时点击第二页又回第一页；每页大小发生实际变化时才回到第一页。
- 角色参数声明为数组，单个 `roles` 参数仍恢复为多选数组；翻页或 URL 改变取消待执行搜索，避免旧防抖回填覆盖导航。文件筛选表单字段名对齐真实字段。
- 角色缓存 finally 只清理自身 Promise，旧代请求结束不会解除新代请求的单飞锁；既有缓存范围不变。
- 上传增加贯穿凭证、XHR、确认的 AbortController，离开页面终止活跃上传；取消后不启动后续传输、确认或回调，上传结束后的合并刷新保留。
- `useLatestRequest` 由内容、举报和审核详情复用；新选择、关闭或离开页面取消旧请求，旧响应/错误不会覆盖当前选择。
- 角色权限创建/编辑加载具备取消与结果隔离，数据未就绪时禁用提交；切换角色不会回填上一角色权限。未改服务端权限判定。
- 用户编辑回填前重置 Form，防止另一用户的密码草稿残留；RoleCards 从父页面接收 roles，解除对子路由 loader 形状的隐式依赖；创建角色组件更正命名。
